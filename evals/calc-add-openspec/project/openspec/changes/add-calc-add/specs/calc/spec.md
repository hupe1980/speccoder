## Purpose
Adds numbers for callers.

## ADDED Requirements

### Requirement: Add numbers
The system SHALL return the sum of two signed 64-bit integers.

#### Scenario: Positive numbers
- **WHEN** a caller adds 2 and 3
- **THEN** the result is 5

#### Scenario: Opposites
- **WHEN** a caller adds -4 and 4
- **THEN** the result is 0
